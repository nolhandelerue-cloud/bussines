# Démonstration — Carrosserie du Centre Ville

## Contenu
- `index.html` : structure de la page
- `style.css` : design responsive
- `script.js` : menu mobile, année automatique et message de démonstration du formulaire

## Lancer le site
1. Décompressez l'archive.
2. Ouvrez `index.html` dans un navigateur.
3. Pour travailler confortablement, ouvrez le dossier dans VS Code et utilisez l'extension Live Server.

## À valider avant toute présentation publique
- Cette réalisation est une maquette de démonstration non commandée par l'entreprise.
- Confirmer le nom, l'adresse, le téléphone, les horaires et toutes les informations de l'entreprise.
- Remplacer les photos d'illustration par des images dont vous avez les droits ou par des photos autorisées du client.
- Ne pas publier de faux avis, de fausses réalisations ou des affirmations non vérifiées.
- Le formulaire ne transmet aucun message. Le connecter à un service d'envoi ou à un backend sécurisé avant mise en production.
- Ajouter les mentions légales et la politique de confidentialité adaptées.
- Vérifier les licences des photos, polices et services externes.
- Les photos et Google Fonts nécessitent une connexion internet.

## Stack
HTML5, CSS3 et JavaScript natif. Pas de framework requis.
